# `coblang` External Test Suite License & Clean-Room Manifest

This document establishes the licensing provenance, SPDX identifiers, pinned upstream revisions, and clean-room isolation rules governing external COBOL test suites used to validate `coblang`.

---

## 1. Clean-Room Architectural Boundary

1. **Compiler & Tooling License (`Apache-2.0 WITH LLVM-exception`)**:
   - All code under `src/` and `tools/` (`coblang-common`, `coblang-scaffold-driver`, `coblang-test-runner`, `coblang-test-importer`, and the future LLVM COBOL frontend) is original work licensed under `Apache-2.0 WITH LLVM-exception`.
2. **Strict One-Way Isolation**:
   - Compiler, driver, and runtime crates MUST NEVER link against, `include_str!`, `include_bytes!`, or copy implementation code from `tests/ported/gnucobol/` or `tests/ported/gcobol/`.
   - External test suites are treated strictly as out-of-process black-box inputs consumed by the test runner via CLI invocation.
   - `scripts/check-quality.sh` enforces this clean-room boundary automatically on every run.

## 3. Provenance Requirements for Generated Test Manifests

Every test manifest generated by `coblang-test-importer` MUST record:
- `upstream_repo`: Canonical upstream URL or archive identifier.
- `upstream_commit`: Exact pinned Git SHA-1 or archive SHA-256.
- `source_file`: Upstream relative file path (e.g., `tests/testsuite.src/syn_move.at` or `gcc/testsuite/cobol.dg/group1/packed.cob`).
- `source_line`: 1-based starting line number in the upstream file.
- `original_test_name`: Upstream test title or filename stem.
- `spdx_license`: Exact SPDX license expression (`GPL-3.0-or-later`, `GPL-3.0-or-later WITH GCC-exception-3.1`, or `NIST-PD`).
